# Íconos del equipo de diseño

`Iconos.pdf` es el original. Cada `.svg` es un ícono recortado de esa hoja, en una caja de
24 × 24 y con `fill="currentColor"`, para que tome el color del texto donde se use.

En la app están como `<symbol id="ri-nombre">` al inicio de `app/index.html`. Dónde va cada uno:

| Ícono        | Dónde                                                  |
| ------------ | ------------------------------------------------------ |
| inicio       | Pestaña Inicio                                         |
| aprender     | Pestaña Aprender                                       |
| biblioteca   | Pestaña Biblioteca                                     |
| perfil       | Pestaña Perfil                                         |
| salir        | Cerrar sesión (menú y perfil)                          |
| cerrar       | Botones de cerrar                                      |
| flecha       | Siguiente, ver más, enviar; girada sirve para «volver» |
| simulacros   | Evaluaciones / Simulacros                              |
| craneo       | Modelo 3D                                              |
| tarjetas     | Flashcards / Tarjetas                                  |
| calendario   | Calendario                                             |
| casos        | Casos clínicos                                         |
| rou          | Estudio con IA                                         |
| mas          | Opciones de vista del modelo 3D                        |
| reiniciar    | Reiniciar y restablecer vista                          |
| ajustes      | Ajustes de Rou                                         |
| alerta       | Errores                                                |
| sin-conexion | Aviso de que no hay internet                           |
| menu         | (el botón de menú dibuja las tres barras con CSS)      |
| enlace       | Sin usar por ahora                                     |
